# ルーティンチェッカー

朝・帰りなど、決まった場面でやることを忘れないためのチェックリスト。
**時刻**または**家にいるかどうか**をきっかけに通知を出し、開くとそのリストが出る。

Tilecheck（mochimono）とは別のアプリ。Tilecheck は位置情報を持たない方針のため分けた。

## 仕様

### リスト

- リストは**自由に増やせる**（例：朝・帰り・休日の朝・出かける前）。並べ替え・複製・削除ができる。
- 1行 = 1項目。
- **チェックは毎日自動で空になる。** 空になる時刻はアプリ全体で1つ、ユーザーが選ぶ（既定 午前3時。
  夜ふかしで日付をまたいでも帰りのリストが消えないように）。
- そろった日時を記録する（一覧に「今日そろった」と出す）。

### 通知のきっかけ（リストごとに1つ選ぶ）

**1. 時刻で通知**
- 曜日と時刻を選ぶ（例：平日 7:00）。複数の時刻も可。
- その日のリストがそろっていれば出さない。

**2. 家にいる間、繰り返し通知**
- 曜日・開始時刻・終了時刻・間隔を選ぶ（既定：平日 18:00〜23:00、1時間ごと）。
- 間隔は 30分 / 1時間 / 2時間。
- 条件：選んだ曜日 かつ 開始〜終了の間 かつ 家にいる かつ まだそろっていない。

**通知を開くと、そのリストが開く。** 通知から「30分後にもう一度」を選べる。

### 家の場所

- 地図で選ぶか「今いる場所を家にする」。範囲は 100m / 150m / 300m から選ぶ（既定 150m）。
- 位置情報は「常に許可」が必要。

### 「家にいる間、繰り返し通知」の仕組み

iOS では、アプリを決まった間隔で起こして位置を確かめることは保証されない。
そこで家の周りの円への**出入り**で起こしてもらい（`CLMonitor`。アプリが閉じていても、再起動後も効く）、
通知は前もって予約しておく。

- **家に入った**：今日の条件に合う毎時（18:00, 19:00, …）の通知を予約する。開始時刻より後に帰ったら、次の区切りから。
- **家を出た**：予約を全部取り消す。
- **そろった**：その日の残りを取り消す。
- 日が変わる・アプリを開く・設定を変える：その時点の状態から予約し直す。

出入りの判定は数分遅れることがある（Wi-Fi・基地局頼みのため）。

### デザイン（リストごとに選ぶ）

- **一覧**：やることを1行に1つ、1列で並べ、いつも全部が見えている。行の高さは項目の数で画面を割って決め、10個くらいまでは1画面に収まる（入りきらない時だけスクロール）。マスやカードの型は一旦やめた（2026-11-15）
- **色のテーマ**：数種類から選ぶ。ライト / ダーク / 自動はアプリ全体で1つ。
- **そろった時の演出**：光る / 紙吹雪 / 控えめ / なし

### プライバシー

- 書いた内容も位置情報も端末の中だけ。**通信はしない。** 位置は「家の中か外か」の判定にだけ使い、履歴は残さない。

## iPhone に入れる

Mac で（Xcode が入っていること）：

```sh
git clone https://github.com/zzzjjj080/routine-checker
cd routine-checker
./install-device.sh
```

iPhone は USB でつなぐ。初めての時は iPhone 側で「デベロッパを信頼」が要ることがある
（設定 → 一般 → VPNとデバイス管理）。Xcode で `RoutineChecker/RoutineChecker.xcodeproj` を開いて ▶ でもよい。

### 試し方

1. 開くと「朝」「帰り」の2つのリストが入っている。通知を「許可」する。
2. 右上の「＋」でリストを足す。リストを開いて「編集」で名前とやること（1行に1つ）を書く。
   いつ知らせるかは別の画面：一覧の各行の🔔の札（またはリスト画面の右上の🔔）を押すと、それだけを変える画面が開く。
3. 「家にいる間」を使うなら、設定（左上の歯車）→ 家の場所 →「今いる場所を家にする」。
   位置情報は「使用中のみ」→「常に許可」の順で2回聞かれる。**「常に許可」にしないと家の出入りが分からない。**
4. 設定に「今：家にいる / 家の外」が出る。家の出入りの判定は数分遅れることがある。

## 構成

```
RoutineCore/              UIに依存しないロジック（swift test で回す）
  Time.swift              時刻・日・「チェックが属する1日」（区切りの時刻）
  Routine.swift           リスト・項目・チェック・きっかけ・見た目
  Planner.swift           今の状態から、どの通知をいつ予約するかを決める
  Store.swift             保存するもの全部（家の場所・区切りの時刻など）
  Theme.swift             色のテーマ6種
RoutineChecker/           Xcodeプロジェクト（iOS 18 以上）
  RoutineCheckerApp.swift 起動。裏で起こされた時も通知の受け口と家の見張りを先に用意する
  AppModel.swift          状態・保存・通知の予約し直し
  Notifier.swift          通知の予約（毎回全部入れ替え）と「30分後にもう一度」
  HomeMonitor.swift       家の出入りの見張り（CLMonitor）と位置情報の許可
  ContentView.swift       一覧
  RoutineView.swift       リストを開いた画面（進み具合の帯・全部外す・見た目）
  Layouts.swift           やることの一覧（1列・1画面に収まる）
  CelebrationOverlay.swift そろった時の演出（光る・紙吹雪・控えめ・なし）
  EditRoutineView.swift   リストの編集（名前・やること）／いつ知らせるか（別の画面）／見た目の選択
  SettingsView.swift      設定と家の場所（地図）
install-device.sh         つないだ iPhone にビルドして入れる
.github/workflows/        GitHub の Mac でテストとビルドを回す
```

### テスト

```sh
cd RoutineCore && swift test
```
