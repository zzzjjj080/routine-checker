# ルーティンチェッカー

朝・帰りなど、決まった場面でやることを忘れないためのチェックリスト。
**時刻**または**家にいるかどうか**をきっかけに通知を出し、開くとそのリストが出る。

Tilecheck（mochimono）とは別のアプリ。Tilecheck は位置情報を持たない方針のため分けた。

## 仕様

### リスト

- リストは**自由に増やせる**（例：朝・帰り・休日の朝・出かける前）。並べ替え・複製・削除ができる。
- 1行 = 1項目。
- **チェックは毎日自動で空になる。** 空になる時刻はアプリ全体で1つ、ユーザーが選ぶ（既定 午前3時。
  夜ふかしで日付をまたいでも帰りのリストが消えないように）。
- そろった日時を記録する（一覧に「今日そろった」と出す）。

### 通知のきっかけ（リストごとに1つ選ぶ）

**1. 時刻で通知**
- 曜日と時刻を選ぶ（例：平日 7:00）。複数の時刻も可。
- その日のリストがそろっていれば出さない。

**2. 家にいる間、繰り返し通知**
- 曜日・開始時刻・終了時刻・間隔を選ぶ（既定：平日 18:00〜23:00、1時間ごと）。
- 間隔は 30分 / 1時間 / 2時間。
- 条件：選んだ曜日 かつ 開始〜終了の間 かつ 家にいる かつ まだそろっていない。

**通知を開くと、そのリストが開く。** 通知から「30分後にもう一度」を選べる。

### 家の場所

- 地図で選ぶか「今いる場所を家にする」。範囲は 100m / 150m / 300m から選ぶ（既定 150m）。
- 位置情報は「常に許可」が必要。

### 「家にいる間、繰り返し通知」の仕組み

iOS では、アプリを決まった間隔で起こして位置を確かめることは保証されない。
そこで家の周りの円への**出入り**で起こしてもらい（`CLMonitor`。アプリが閉じていても、再起動後も効く）、
通知は前もって予約しておく。

- **家に入った**：今日の条件に合う毎時（18:00, 19:00, …）の通知を予約する。開始時刻より後に帰ったら、次の区切りから。
- **家を出た**：予約を全部取り消す。
- **そろった**：その日の残りを取り消す。
- 日が変わる・アプリを開く・設定を変える：その時点の状態から予約し直す。

出入りの判定は数分遅れることがある（Wi-Fi・基地局頼みのため）。

### デザイン（リストごとに選ぶ）

- **見た目の型**：マス（色付きのマスをタップ） / リスト（縦に並ぶ） / カード（1つずつ大きく出し、タップかスワイプで次へ）
- **色のテーマ**：数種類から選ぶ。ライト / ダーク / 自動はアプリ全体で1つ。
- **そろった時の演出**：光る / 紙吹雪 / 控えめ / なし

### プライバシー

- 書いた内容も位置情報も端末の中だけ。**通信はしない。** 位置は「家の中か外か」の判定にだけ使い、履歴は残さない。

## 構成

```
RoutineCore/              UIに依存しないロジック（swift test で回す）
  Time.swift              時刻・日・「チェックが属する1日」（区切りの時刻）
  Routine.swift           リスト・項目・チェック・きっかけ・見た目
  Planner.swift           今の状態から、どの通知をいつ予約するかを決める
  Store.swift             保存するもの全部（家の場所・区切りの時刻など）
  Theme.swift             色のテーマ6種
RoutineChecker/           Xcodeプロジェクト（SwiftUI・CLMonitor・UserNotifications）※これから
```

### テスト

```sh
cd RoutineCore && swift test
```
